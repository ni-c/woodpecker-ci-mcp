## 71 tools, or eight

The tool list is not fixed. `WOODPECKER_ALLOW_TOOLS=essential` narrows it to the
eight that cover the job end to end — find the repository, read its pipelines and
logs, run one again — and a name that matches nothing stops the server instead of
quietly leaving a tool out of `tools/list`.

![Finding a failed pipeline, reading the failing step's log, and restarting it](/demo.gif)

Recorded from `docs/demo.tape` against a throwaway instance. The server starts
without any configuration at all, so registries and inspectors can introspect it;
every call then fails with setup instructions instead of reaching the API.
